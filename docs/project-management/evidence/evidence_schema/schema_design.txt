ZeroShield AI - ZS-021 Common Evidence Record Design

Schema version: 1.0.0

Supported evidence sources:
Suricata = signature_alert
Zeek = network_telemetry
XGBoost = supervised_classification
Isolation Forest = anomaly_evidence

Common evidence fields:
schema_version
evidence_id
incident_id
source
evidence_type
timestamp
ingested_at
source_ip
source_port
destination_ip
destination_port
protocol
detector_data
provenance
interpretation
raw_evidence

Design principle:
All detectors use one common evidence envelope while detector-specific semantics and provenance remain separate.

Suricata represents deterministic signature/rule-match evidence.
Zeek represents passive network telemetry/context only.
XGBoost probabilities apply only among classes represented during supervised training.
Isolation Forest provides anomaly/novelty evidence relative to learned benign reference behaviour.

ZeroShield does not collapse heterogeneous evidence into a universal maliciousness or zero-day probability.
